  • Data security posture management for agent interactions

Microsoft Defender · threat protectionIs it being attacked or misused?
  • Agent posture management and attack paths to critical assets
  • Real-time detection and blocking of malicious tool invocations
  • Unified agent logs for investigation and hunting
Where this altitude stops. Agent 365 governs who an agent is, what data it touches and whether it's under attack. It doesn't decide how the Azure resources that host Foundry agents are built. For that, zoom in.

500 ft · Agent

Foundry governs what each agent may run, call, reach and spend

Each agent control is set in one of two places. Outside Foundry, an Azure Policy assigned in the Azure portal checks the configuration when it's saved. Inside Foundry, a setting in ai.azure.com or the project API is enforced at runtime. Three concerns need both. Click a row for the details.

500 ft · Agent types

Not every agent policy covers every kind of agent

Hosted agents run your own code in a container. Some policies check only hosted agents, and some can't see inside them at all. Check which agent types a customer runs before promising coverage.
